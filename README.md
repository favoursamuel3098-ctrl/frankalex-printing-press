## Features
- Customer-facing printing catalog
- Shopping cart and checkout
- Order IDs and tracking IDs
- Customer order history and tracking
- Secure backend order APIs
- Admin order management
- Live order updates
- Responsive mobile-first interface
- Printing services catalog

## Stack
- React + Vite + TypeScript
- Tailwind CSS
- Lucide React
- AppDeploy backend SDK for database, API and realtime functionality

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
The production version is deployed through AppDeploy. Backend routes use the AppDeploy SDK and therefore require the AppDeploy runtime for full database/realtime functionality.

## Important
Never commit passwords, API keys, payment gateway secrets, or other private credentials to this repository. Configure secrets through the deployment platform.
